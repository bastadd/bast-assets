# bast-assets

Fichiers statiques du site Bast servis via jsDelivr.

- `hero/desktop/knight_0001.webp` … `knight_0101.webp` : séquence du Hero (1920×1080)
- `crown/crown_0001.webp` … `crown_0090.webp` : couronne de la section Projets (572×468, fond transparent)
- `hero/mobile/` : même séquence recadrée en portrait (810×1080)
- `hero2/desktop/knight_0001.webp` … `knight_0201.webp` : nouvelle séquence du Hero, 201 images à fond transparent (1920×1080)
- `hero2/mobile/` : même séquence recadrée en portrait (810×1080), fondu transparent en bas
